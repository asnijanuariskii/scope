# Project

Full-stack application.

## Structure

- `backend/` — API server
- `frontend/` — Web app
- `tests/` — All tests (unit, integration, e2e, security, uiux)
- `docs/` — Documentation, OpenAPI spec, decision log
- `infra/` — Docker, Nginx, deploy scripts
- `.kiro/` — AI agents, steering, hooks, specs

## Getting Started

1. Clone the repo
2. Configure MCP servers in `~/.kiro/settings/mcp.json`
3. Set up environment variables
4. Run with Docker: see `infra/`
